PDF·EPUB·TXT를 내 방식으로 읽기

페이지의 모양을 유지하는 책과 글자가 다시 배치되는 책은 읽기 설정도 다릅니다.

파일읽는 방식먼저 조절할 것
PDF정해진 페이지 배치를 유지합니다.확대와 화면에 맞추기
EPUB일반적인 텍스트 책은 화면 폭에 맞춰 글을 배치합니다.글자 크기와 읽기 설정
TXT텍스트를 읽기 화면으로 표시합니다.글자 크기와 파일의 문자 인코딩

책 열기부터 이어 읽기까지

  1. 페이지모아의 책 열기로 본인 파일을 선택합니다.
  2. 읽기 메뉴의 설정에서 형식에 맞는 크기와 보기 방식을 정합니다.
  3. 책 목록으로 돌아가면 다른 책을 고를 수 있고, 홈에서는 읽던 책을 이어 볼 수 있습니다.

페이지 표시가 글을 가리나요?

페이지 표시 설정에서 표시 여부와 크기·투명도를 조절하세요. 화면을 덜 가리도록 줄이거나 숨길 수 있습니다. 글자 크기를 바꾸면 텍스트의 화면상 배치가 바뀔 수 있으므로 단순히 화면 모양보다 읽던 문장을 기준으로 확인하세요.

글자가 깨지거나 책이 비어 보일 때

다른 정상 파일과 비교하고, TXT라면 원본 인코딩을 확인하세요. 스캔 PDF의 글자는 이미지이므로 텍스트 크기 조절과 동일하게 바뀌지 않습니다. DRM이나 제공자 전용 암호화가 적용된 전자책은 일반 파일과 다르며 호환을 보장하지 않습니다.

파일을 지우기 전에

앱의 독서 기록과 원본 파일은 구분됩니다. 원본을 이동하거나 접근 권한을 취소하면 다시 파일을 선택해야 할 수 있습니다. 중요한 파일은 별도로 보관하세요.
