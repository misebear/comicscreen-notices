Android에서 CBZ·ZIP 만화책 읽기

만화 이미지가 들어 있는 CBZ나 ZIP 파일을 페이지모아에서 열면, 페이지를 각각 꺼내지 않고 책처럼 읽을 수 있습니다.

CBZ는 어떤 파일인가요?

CBZ는 보통 만화 이미지를 ZIP으로 묶은 파일입니다. 확장자만 바꾼다고 손상된 압축 파일이 복구되지는 않습니다. 원본 파일을 보관하고, 정상적으로 다운로드가 끝난 파일로 시작하세요.

기기에서 열기

  1. 본인이 사용할 권한이 있는 CBZ 또는 ZIP 파일을 휴대폰·태블릿의 접근 가능한 폴더에 둡니다.
  2. 페이지모아의 책 열기에서 파일을 선택합니다. 여러 권을 관리하려면 필요한 폴더만 연결합니다.
  3. 읽기 메뉴에서 현재 파일과 페이지를 확인합니다. 책 목록으로 돌아가 다른 권을 고르거나 홈에서 이어 읽습니다.

큰 책은 저장공간을 얼마나 쓰나요?

지원되는 로컬 ZIP·CBZ에서는 원본 전체를 앱 저장소에 다시 복사하지 않는 직접 읽기 경로를 사용합니다. 페이지 캐시와 표지는 별도 공간을 사용할 수 있습니다. 파일 제공자나 압축 구조에 따라 호환 읽기 또는 복사가 필요할 수 있으므로 모든 파일의 추가 공간이 0이라고 보장하지 않습니다.

현재 파일 크기 한도는 2GiB입니다. 기존 1GB 제한이 늘어난 것이며 무제한은 아닙니다. 새 책을 처음 열 때는 파일 확인 때문에 다시 여는 경우보다 오래 걸릴 수 있습니다.

파일이 열리지 않을 때

  • 다운로드가 끝났는지, 기기에 여유 공간이 있는지 확인하세요.
  • 파일을 옮겼다면 책 열기에서 새 위치를 다시 선택하세요.
  • 다른 책이 열리는지 비교해 특정 파일 문제인지 확인하세요.
  • 암호화·손상·분할 압축이나 특수한 압축 방식은 별도 지원 확인이 필요합니다.

문의에는 기기 모델·앱 버전·파일 형식·크기·오류 문구를 알려주세요. 비공개 책 원본이나 서버 비밀번호를 보내지 않아도 됩니다.
